## 4. 已完成的模块

### 编码器测距 ✅

- 问题：跑 20~30 cm 就停（软件以为到 1 m）
- 根因：factor 大 2.4 倍 + 减速箱记错
- 标定：8 次推 1 m（每次前后清零）→ 左 52149 / 右 51260 计数
- 验证：手推 1 m 显示 966 mm（3.4%，手推本身精度极限）；电机驱动跑满 1 m，`DIST` 995~1005

### 直行 PID 🟡

- 触发：按 PB14 → `GO` → 走 1 m → `DIST` → `STOP`
- 上电不动（已修复「上电自动连续跑 1 m」的 bug）
- **问题：持续左偏约 10 cm / 1 m**
- 原因：右轮慢 18% 的恒定扰动；P 项留稳态误差，I 项（KI=0.8、限幅 150）出力不足

### 陀螺仪 ✅

- 零偏标定、符号统一（`GYRO_SIGN = -1`，右转为正）
- 逆时针整圈 367.6°（误差 2.1%）
- 按 PB14 时同步清角度

### 光电管 ✅

- 12 路电位器硬件标定完成
- 软件位图 `S,<12位>,<err×10>` 正常
- err 符号 / 路序已验证

### 电机 ✅ / ⚠️

- 死区：左 250 / 右 500，已在 `Motor_Set()` 内补偿
- ⚠️ 右轮机械阻尼大、同 PWM 慢 18%（决定不修，靠软件补）

## 5. 已知问题（接手必看）

| # | 问题 | 影响 |
|---|---|---|
| 1 | **车持续左偏** | 明天第一件事，见第 6 节 |
| 2 | 陀螺仪没有低通滤波 | 电机一转角速度噪声 ±300 °/s，D 项会输出 ±1200（被限幅）→ 车轮可能抖 |
| 3 | `TURN_MAX 450 / TIMEOUT 8000` 偏松 | 失控时可能原地转，建议 250 / 3000 |
| 4 | 没有急停 | 跑起来只能等到点或按 rst，测试时前方留 1.5 m |
| 5 | 断电后滑行 3~5 cm | `DIST` 是断点时刻，卷尺会多几厘米，属正常 |
| 6 | 电池电压影响 | 满电与亏电速度差 15%，参数会“跑掉” |
| 7 | 右轮先天不对称 | 所有速度环必须左右独立 |

## 6. 下一步（按顺序）

### 第 1 步：修正左偏（30 分钟，最重要）

**方案 A：加固定偏置（最快）**

在 `STRAIGHT_TURN_MAX` 附近加：

```c
#define STRAIGHT_TURN_BIAS  (-100)   /* 负值 = 让右轮多出力 */
```

在 `turn = ...` 那行末尾加 `+ STRAIGHT_TURN_BIAS;`

| 试跑结果 | 调整 |
|---|---|
| 还往左偏 | −100 → −140 → −180 |
| 变成右偏 | −100 → −60 → −40 |
| 走直 | ✅ 定稿 |

**方案 B：加大积分（治本）**

```c
static float sp_ki = 4.0f;   /* 0.8 → 4.0 */
/* 积分限幅 150 → 80 */
```

两者配合：偏置吃恒定部分，积分吃慢变部分。

### 第 2 步：验证直线（20 分钟）

| 判据 | 合格 |
|---|---|
| 1 m 横向偏移 | < 3 cm |
| 停止时车头角度 | 与出发方向夹角 < 3° |
| `V` 行角度列 | 全程 ±15 内，不单向增长 |

### 第 3 步：拍视频③（10 分钟）

贴起止线 → 手机侧面拍 → 按 PB14 → 走完。

### 第 4 步：之后

- **视频②**：原地转 4×90°（陀螺仪角度闭环 + 两轮反向等速）
- **视频①**：连跑两圈（循迹 PD + 速度环，工作量最大）

## 8. 串口协议（115200 8N1）

```
上电：    IMU,0                      陀螺仪初始化结果
          GB,-4                      零偏 ×10
          ENC,READY                  编码器就绪

待机：    ENC,左计数,右计数,里程mm,速度mm/s      每 100 ms

按 PB14： GO
跑车中：  V,剩余mm,角度×10,角速度×10            每 100 ms
          DIST,实际里程mm
          STOP
```

所有数值都是**整数×10**，不用浮点（MDK-Lite 32 KB 装不下 `%f`）。

## 11. 关键设计说明

| 设计 | 原因 |
|---|---|
| 负压风扇用「TIM1 更新 + DMA 写 BSRR」 | TIM1 各通道共用计数器，10 kHz 与 50 Hz 无法共存 |
| 编码器 32 位累加 | 16 位 CNT 走几厘米就回绕 |
| 1 ms 中断只做整数累加 | 浮点 + printf 会拖垮 1 kHz 时基 |
| 打印全部放主循环并限速 | `fputc` 单字节阻塞发送，每字节约 87 µs |
| 不用 `%f` | 浮点 printf 约 5.4 kB，MDK-Lite 会报 L6047U |
| 两轮 factor 分开 | 左右轮直径/磨损不同，且右轮慢 18% |

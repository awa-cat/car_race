| 参数 | 值 | 说明 |
|---|---|---|
| `ISL_MODE` | **2** | 0=关 1=干跑 2=启用 |
| `ISL_TURN_DIR` | **+1** | 逆时针（左转），方形环岛方向 |
| `ISL_W_DPS` | 85 | 目标角速度 °/s（800 mm 周长 / 150 mm/s ≈ 67，留余量到 85） |
| `ISL_V` | 150 | 岛内速度 |
| `ISL_BIAS / ISL_BIAS_MAX` | 120 / 300 | 角速度环偏置基准与上限 |

| `ISL_EXIT_DEG` | 340 | 累计偏航多少度算出岛 |
| `ISL_MIN_MS` | **300** | 进岛后最少停留时间（防 gyro 尖峰导致瞬间出岛） |
| 进岛判据 | 图案 | `路数 ≥ ISL_N_WIDE` 且 **最左、最右两路同时为白** = T 口；普通 90° 弯只有一端白 → 不触发。**不用编码器里程** |
| `ISL_CONFIRM_MS` | 20 | 图案连续成立多久才认账（车压过横线只有 ~57 ms，原来 200 ms 永远触发不了） |
| `ISL_NEAR_N` | 5 | 路数达到这个值就先降速（进岔口前的预减速，同样只看图案） |

> ⚠️ 环岛入口实测（三次运行）：`0EFF`（11 路白）出现在 2811 / 2857 / 2888 mm，重复性 ±40 mm。
> `ISL_CONFIRM_MS` 必须小于车通过横线的时间，否则一次都不会触发。

> ⚠️ **`Drive_Straight_PID(742)` 是经验值**：软件数到 742 mm 就断电，实际车停在约 1000 mm。
> 差的 258 mm 来自「断电滑行 + 低速段减速」，不是 factor 误差（手推 1 m 时里程是准的）。
> 换地面、换 PWM、换电池后这个数要重标。

## 4. 已完成的模块

### 编码器测距 ✅

- 问题：跑 20~30 cm 就停（软件以为到 1 m）
- 根因：factor 大 2.4 倍 + 减速箱记错
- 标定：8 次推 1 m（每次前后清零）→ 左 52149 / 右 51260 计数
- 验证：手推 1 m 显示 966 mm（3.4%，手推本身精度极限）；电机驱动跑满 1 m，`DIST` 995~1005

### 直行 PID 🟡

- 触发：按 PB14 → `GO` → 走 1 m → `DIST` → `STOP`
- 上电不动（已修复「上电自动连续跑 1 m」的 bug）
- **问题：持续左偏约 10 cm / 1 m**
- 原因：右轮慢 18% 的恒定扰动；P 项留稳态误差，I 项（KI=0.8、限幅 150）出力不足

### 陀螺仪 ✅

- 零偏标定、符号统一（`GYRO_SIGN = -1`，右转为正）
- 逆时针整圈 367.6°（误差 2.1%）
- 按 PB14 时同步清角度

### 光电管 ✅

- 12 路电位器硬件标定完成
- 软件位图 `S,<12位>,<err×10>` 正常
- err 符号 / 路序已验证

### 电机 ✅ / ⚠️

- 死区：左 250 / 右 500，已在 `Motor_Set()` 内补偿
- ⚠️ 右轮机械阻尼大、同 PWM 慢 18%（决定不修，靠软件补）

## 5. 已知问题（接手必看）

| # | 问题 | 影响 / 现状 |
|---|---|---|
| 1 | **六边形环岛不会进** | 距离窗只覆盖方形环岛（2650~3050 mm），六边形在别的位置，永远不会武装 |
| 2 | **进岛瞬间可能"假出岛"** | 已加 `ISL_MIN_MS = 300`：进岛 300 ms 内不允许按偏航出岛 |
| 3 | 圈长靠里程推算 | `FOLLOW_LAP_MM = 7190` 是日志推算值，打滑会让它漂 ±40 mm/圈 |
| 4 | 陀螺标定偶尔失败 | 上电瞬间手碰车 → 零偏 16~23 °/s（正常应 <1）。日志出现 `GB,168` 这种就是失败的 |
| 5 | SPI 等待无超时 | `bmi270_port.c` 里 `while (spi_dma_tx_rx_complete == 0)`，DMA 异常会死机 |
| 6 | `stall_ms` 跨次发车不复位 | 函数内 `static`，第二次发车可能误报 `STALL` |
| 7 | 右轮先天慢 18%、死区 600/300 | 靠每轮速度环吃掉，不要用开环 PWM |
| 8 | 环路 100 ms 打两条日志 | 115200 下约 3.5 ms，会让 10 ms 控制周期抖动 |

## 6. 下一步（按顺序）
### 第 1 步：验证新判据（10 分钟）

进岛已改成**纯图案判据**，不再用编码器里程。先干跑一圈确认它认不认：

```c
#define ISL_MODE        1      /* 干跑：只打印，不动作 */
```

跑完整一圈，看：

```
ISL,DRY,<里程mm>,<白路数>,<12位位图>
```

位图解码（ch0 = bit11 = 物理最左，白 = 1）：

| 位图 | 两端 | 判为 |
|---|---|---|
| `0EFF` | 左白 + 右白 | ✅ 环岛 T 口（方形入口实测值） |
| `0FFF` | 左白 + 右白 | ✅ 环岛 T 口 |
| `0FF8` | 左白、右蓝 | ❌ 普通 90° 弯 |
| `03FF` | 左蓝、右白 | ❌ 普通 90° 弯 |
| `0FFC` | 左白、右蓝 | ❌ 会被当成普通弯（若第二圈漏进岛，看这里） |

### 第 2 步：按日志微调判据

如果日志里环岛入口的位图**不是两端都白**（例如第二圈出现 `0FFC`），
就把 `Island_Pattern()` 的条件放宽一档：

```c
/* 原来：两端都白 */
return (uint8_t)(end_l && end_r);

/* 放宽：两端都白，或"左端白且路数 ≥ 10" */
return (uint8_t)((end_l && end_r) || (end_l && n >= 10U));
```

改之前先确认普通直角弯不会同时满足，否则会误触发。

### 第 3 步：六边形

六边形是 30°/60° 的浅角，建议照 `Core/Src/island_nav.c` 里 `NAV_HEX_*` 的做法，
在 `Island_Step` 里按形状分支，用不同的 `ISL_EXIT_DEG` 和目标角速度。

### 第 4 步：把"越跑越慢"彻底解决

队友在提交信息里记过：**「绕圈后转速会减小，电机堵住然后冲出赛道」**。排查顺序：

1. 跑完量电池电压（< 7.0 V 就是掉压）
2. 看 `F` 行的 `uL/uR` 是否撞到 3000（速度环拧到头）
3. 摸电机温度（右轮先天阻力大）

### 第 5 步：拍视频①

| 判据 | 合格 |
|---|---|
| 连续 3 次跑完两圈 | 不掉线、不误进岛 |
| `LAPS,DONE` 时里程 | ≈ 14380 mm（2 × 7190） |
| 单圈时间 | 记录基线，之后用来对比调参效果 |

### 第 6 步（可选）：接入 `island_nav.c`

工程里有一份**没编译进 Keil** 的环岛状态机（`Core/Src/island_nav.c`，239 行，含主机单元测试）：

- 方形 / 六边形形状区分，转角 90° 与 30°/60° 分开
- 编码器定距推进 → 停车等稳 → 原地转 → 抓线 → 下一角
- 9 种故障码，出错即锁停

它不是"连续转向"方案，而是"停-转-停"方案。几何上更稳，但需要实车标定推进量。
要是连续转向始终过不了六边形，就走这条路。

## 8. 串口协议（115200 8N1）

```
上电：    IMU,0                      陀螺仪初始化结果
          GB,-4                      零偏 ×10
          ENC,READY                  编码器就绪

待机：    ENC,左计数,右计数,里程mm,速度mm/s      每 100 ms

跑车中：  V,剩余mm,角度×10,角速度×10            每 100 ms
```

## 11. 关键设计说明

| 设计 | 原因 |
|---|---|
| 负压风扇用「TIM1 更新 + DMA 写 BSRR」 | TIM1 各通道共用计数器，10 kHz 与 50 Hz 无法共存 |
| 编码器 32 位累加 | 16 位 CNT 走几厘米就回绕 |
| 1 ms 中断只做整数累加 | 浮点 + printf 会拖垮 1 kHz 时基 |
| 打印全部放主循环并限速 | `fputc` 单字节阻塞发送，每字节约 87 µs |
| 不用 `%f` | 浮点 printf 约 5.4 kB，MDK-Lite 会报 L6047U |
| 两轮 factor 分开 | 左右轮直径/磨损不同，且右轮慢 18% |

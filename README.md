### 循迹（视频①）参数 · main.c

> 分层：`Line_Read`（传感器）→ `Line_Shape`（误差整形）→ `Steer_PD`（转向）
> → 左右分配 → `Inc_PID`（每轮速度）→ `Follow_Line_Run`（阶段 + 状态机）。

| 参数 | 值 | 说明 |
|---|---|---|
| `RUN_MODE` | **2** | 0=直行 1=原地转 2=循迹 |
| `FOLLOW_LAP_MM` | **7190** | 单圈里程，日志推算（10068−2879），不是卷尺值 |
| `FOLLOW_V_FAST / SLOW` | 300 / 180 | 正中/最歪时的目标速度 mm/s |
| `FOLLOW_KP / KI / KD` | 150 / 0.8 / 18 | 转向环；KD 是"每 10 ms 差分"，等效增益 = KD×100 |
| `FOLLOW_TURN_MAX` | 350 | 差速限幅 |
| `FOLLOW_TURN_SIGN` | **−1** | 已实测确定，别乱改 |
| `FOLLOW_V_MIN` | −120 | 内轮允许反转（会被 `Motor_Set` 的死区补偿放大） |
| `FOLLOW_LOST_MS` | 400 | 丢线 400 ms 后进入找线，找 1.5 s 不回才停车 |

### 环岛参数 · main.c

**核心思路：按赛道的固定顺序走，不让车去"猜形状"。**

一圈里先方形、后六边形，所以用 `isl_phase` 决定当前该响应哪种图案：

| 阶段 | 只响应 | 切换条件 |
|---|---|---|
| `PHASE_SQ`（起点） | T 口 | 穿过 2 次（进 + 出）→ `PHASE_HEX` |
| `PHASE_HEX` | 分叉 | 出环完成 → `PHASE_SQ` |

| 环节 | 参数 | 值 | 说明 |
|---|---|---|---|
| 起点 | `ISL_FIRST_PHASE` | `PHASE_SQ` | 先方形后六边形 |
| 方形入口 | `ISL_T_N` | **11** | 白路数 ≥11 判为 T 口（实测 T 口 11~12 路，方框拐角最多 10） |
| 方形穿越 | `ISL_CROSS_MM` / `ISL_CROSS_V` | 60 / 200 | 锁定直行 60 mm、速度 200；T 口处 12 路平均≈0，PD 方向不可信 |
| 六边形入口 | `ISL_FORK_N` / `ISL_FORK_MM` | **5 / 60** | 路数 ≥5 且持续 60 mm（普通弯的宽区只有 30~50 mm） |
| 六边形速度 | `ISL_HEX_V` | **300** | 六边形转弯不剧烈，**不减速**；固定值避免速度在 294/200 间跳 |
| 出环触发 | `ISL_EXIT_DEG` | **345** | 绕满一圈（300° 时实测还差 60° 没走完） |
| 出环动作 | `ISL_EXIT_CROSS_MM` | **220** | 锁定直行穿过岔口，防止 PD 又沿环走 |
| 防重入 | `ISL_RET_MM` | 600 | 出环后 600 mm 内不许再进岛 |
| 兜底 | `ISL_OVER_DEG` / `ISL_SES_MAX_MS` | 430 / 20 s | 超限强制结束，防无限绕圈 |

> ⚠️ **判据的历史教训**（改之前务必看）：
> - 判据曾经加过"最左与最右同时有白"，结果 4 次经过六边形一次都没触发——
>   入口位图在 `079E(左) → 02FC(右) → 0E07(两端)` 之间快速跳变，
>   "两端都白"只占一帧，配合"持续 60 mm"永远满足不了。**只有白路数是稳定特征。**
> - 出环曾经"绕满 345° 就直接交还 PD"，结果车在环里又绕了约两圈（多跑 1950 mm）——
>   分叉处 PD 会把两条线的平均当居中。**必须锁直行穿过岔口。**


> ⚠️ **`Drive_Straight_PID(742)` 是经验值**：软件数到 742 mm 就断电，实际车停在约 1000 mm。
> 差的 258 mm 来自「断电滑行 + 低速段减速」，不是 factor 误差（手推 1 m 时里程是准的）。
> 换地面、换 PWM、换电池后这个数要重标。

### 关键换算

```
这台车是 1:200 减速箱（不是教程假设的 1:20）
每圈计数 ≈ 10400 ~ 10600
每米计数 ≈ 51700
```

## 4. 已完成的模块

### 编码器测距 ✅

- 问题：跑 20~30 cm 就停（软件以为到 1 m）
- 根因：factor 大 2.4 倍 + 减速箱记错
- 标定：8 次推 1 m（每次前后清零）→ 左 52149 / 右 51260 计数
- 验证：手推 1 m 显示 966 mm（3.4%，手推本身精度极限）；电机驱动跑满 1 m，`DIST` 995~1005

### 直行 PID 🟡

- 触发：按 PB14 → `GO` → 走 1 m → `DIST` → `STOP`
- 上电不动（已修复「上电自动连续跑 1 m」的 bug）
- **问题：持续左偏约 10 cm / 1 m**
- 原因：右轮慢 18% 的恒定扰动；P 项留稳态误差，I 项（KI=0.8、限幅 150）出力不足

### 陀螺仪 ✅

- 零偏标定、符号统一（`GYRO_SIGN = -1`，右转为正）
- 逆时针整圈 367.6°（误差 2.1%）
- 按 PB14 时同步清角度

### 光电管 ✅

- 12 路电位器硬件标定完成
- 软件位图 `S,<12位>,<err×10>` 正常
- err 符号 / 路序已验证

### 电机 ✅ / ⚠️

- 死区：左 250 / 右 500，已在 `Motor_Set()` 内补偿
- ⚠️ 右轮机械阻尼大、同 PWM 慢 18%（决定不修，靠软件补）

## 5. 已知问题（接手必看）

| # | 问题 | 影响 / 现状 |
|---|---|---|
| 1 | **出环偶发失败** | 出环要求"偏航 ≥345° 且看到分叉"两个条件同时成立；入口位图异常（如 `0C1E`）时车走环路径不同，可能到 345° 不在岔口，会多绕（实测出现过绕到 412°、耗时 13.5 s） |
| 2 | 六边形偶发漏检 | 13.txt 里出现过 `PHASE,SQ,SKIP`（30 s 内 `n≥5` 没持续 60 mm） |
| 3 | 陀螺标定偶尔失败 | 上电瞬间手碰车 → 零偏 16~23 °/s（正常应 <1）。日志出现 `GB,168` 就是失败，整轮数据作废 |
| 4 | 圈长靠里程推算 | `FOLLOW_LAP_MM = 7190` 是日志推算值，打滑会让它漂 ±40 mm/圈 |
| 5 | SPI 等待无超时 | `bmi270_port.c` 的 `while (spi_dma_tx_rx_complete == 0)`，DMA 异常会死机，电机保持最后输出 |
| 6 | 右轮先天慢 18%、死区 600/300 | 靠每轮速度环吃掉，不要用开环 PWM |
| 7 | 100 ms 打一行 F（约 50 字节） | 115200 下约 4 ms，占控制周期 40%，节拍会抖 |
| 8 | 拿起车会触发 `STALL` | 两轮悬空、目标 >100 → 判堵转停车。可当急停用，但要知道原因 |

### 第 2 步：按失败模式定位

| 现象 | 日志特征 | 改哪里 |
|---|---|---|
| 六边形没进 | `PHASE,HEX,SQ2` 后无 `ISL,FIN` | `ISL_FORK_MM` 60 → 40 |

| 出环后仍在环里 | `SOUT` 后位图还是 `0E0E` 这类两端白 | `ISL_EXIT_CROSS_MM` 220 → 300 |
| 出环后又进岛 | `SOUT` 后 600 mm 内又 `ISL,FIN` | `ISL_RET_MM` 600 → 1000 |

## 8. 串口协议（115200 8N1）

```
上电：    IMU,0                              陀螺仪初始化，0=成功
          GB,<零偏×10>,SD,<方差>             零偏应 -20~20
          ENC,READY                          编码器就绪

按 PB14： GO
          PHASE,SQ,START                     从方形阶段开始
          FOLLOW,START

运行中：  F,状态,里程,err×10,目标×10,vL×10,vR×10,uL,uR,路数,位图
          状态：0=循迹 1=穿越T口 2=找线     每 100 ms 一行

方形环岛：ISL,IN,<路数>,<位图>,<里程>         识别到 T 口
          ISL,OUT,<穿越 mm>                  通常 60~62
          PHASE,HEX,SQ2                      两次穿越完成，切六边形阶段

六边形：  ISL,FIN,<路数>,<位图>,<里程>         识别到分叉
          ISL,SEX,<偏航×10>,<路数>            绕满 345°，开始出环
          ISL,SOUT,<穿越 mm>,<路数>           锁定直行穿完岔口，通常 220
          PHASE,SQ,HEXDONE                   切回方形阶段

异常：    ISL,SOVR,<偏航×10>                超过 430° 强制结束
          PHASE,*,SKIP                       某阶段 30 s 没等到图案
          STALL / LOST / TIMEOUT / ABORT     结束原因
          FOLLOW,STOP,<总里程mm>
```

所有数值都是**整数×10**，不用浮点（MDK-Lite 32 KB 装不下 `%f`）。
`位图` 是 12 位十六进制，**ch0 = bit11 = 物理最左**，白 = 1。

## 11. 关键设计说明

| 设计 | 原因 |
|---|---|
| 负压风扇用「TIM1 更新 + DMA 写 BSRR」 | TIM1 各通道共用计数器，10 kHz 与 50 Hz 无法共存 |
| 编码器 32 位累加 | 16 位 CNT 走几厘米就回绕 |
| 1 ms 中断只做整数累加 | 浮点 + printf 会拖垮 1 kHz 时基 |
| 打印全部放主循环并限速 | `fputc` 单字节阻塞发送，每字节约 87 µs |
| 不用 `%f` | 浮点 printf 约 5.4 kB，MDK-Lite 会报 L6047U |
| 两轮 factor 分开 | 左右轮直径/磨损不同，且右轮慢 18% |
| **环岛用「阶段序列」而不是形状识别** | 方形 T 口与六边形分叉在光电管上图案重叠，靠图案分不干净；赛道一圈固定是"先方形后六边形"，按顺序走最可靠 |
| **T 口穿越时锁直行** | T 口 12 路平均趋近 0，PD 方向不可信 |
| **出环锁直行 220 mm 穿过岔口** | 分叉处 PD 会把两条线的平均当居中，直接交还 PD 会沿环再走一圈 |
| **陀螺 ≥900 °/s 的帧整帧丢弃** | SPI 偶发坏帧会让角度积分瞬间甩出几十度，曾导致"刚进岛就判出岛" |

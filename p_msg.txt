=== 090475c 修"假进岛退出后转向偏移没清干净"（车一直往左偏的元凶）
现象：车有时在循迹时一直向左偏，把"线稍稍偏左"当成自己的中心。
原因：环岛进岛阶段会设 isl_err_off = ±ISL_ENTRY_OFF(2.5) 做"补线"，
      假进岛（ISL,FABORT）是在进岛阶段退出的，那时偏移正好是 -2.5，
      而 FABORT 分支没有清它。

后果：e = Line_Shape(...) + Island_ErrOffset() 每帧都被 -2.5 顶住，
      线在正中时 r = 150*(-2.5) + 40*(-2.5)*2.5 = -625，车一路向左打死，
      直到线被挤到左侧 2.5 格才认为"回中"。
      而且它只在下次会话结束/换圈时才清 —— 等于整圈都带着这个偏移跑。

改动 1（关键）：ISL,FABORT 分支加 isl_err_off = 0.0f
  其它退出路径（SEX / SEX_T / SEX_F / HEXOVER）本来就都清了，只有这条漏了。

改动 2：BS,SOVR（大套小单段超里程强退）也补 bs.err_off = 0.0f
  原来要等 BS_OUT 走完 300 mm 才清，这 300 mm 里偏置一直顶着转向。

只加两行赋值，不碰任何控制参数。编译 0 error 0 warning，Code 39.6 KB

=== 002427c 方形计数：补上换格清零 + 两次 T 口的合理间隔窗口
问题（46.txt 实测）：
  四次"方形两次穿越"的间隔分别是 664 / 412 / 1667 / 2405 mm，
  只有 664 是正常的（历史正常值 675~1030）。
  412 = 同一个口被数两次；1667 / 2405 = 已经走到下一个元素了。
  方形一乱计数，计划表就错位，后面八边形、第 8 格、门全部跟着错。

改动 1：Island_Advance() 清方形计数
  原来只清 isl_cfm，不清 sq_events。
  某格只穿了一次就被跳过（HEXOVER / H8NC / 30 s 超时 / RESYNC），
  残留的计数会让下一个方形格只穿一次就 SQOK —— 连跳两格，且没有任何日志。
  现在 Island_Advance() 同时清 sq_events 和 sq_d0。

改动 2：两次 T 口加间隔窗口
  新增 SQ_MIN_GAP_MM 450 / SQ_MAX_GAP_MM 1300
  第一次穿越：记下 sq_d0
  第二次穿越：
    gap < 450   -> 打印 SQ,CLOSE,<gap>，不计数（同一个口）
    gap > 1300  -> 打印 SQ,FAR,<gap>，把这次当新的第一次
    450~1300    -> 正常完成一格（SQOK）
  新增 sq_d0 变量，记录第一个 T 口的里程。

改动 3（辅助）：PLAN 打印加上换格时的里程
  PLAN,x/10,SQ,<理由>,<里程>
  以后每次跳格都能直接看到"在哪一米跳的"。
